# Study Tracker

A browser-based study tracker built with HTML, CSS, and JavaScript.

## Open locally

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.

No build step or package installation is required.

## Main pages

- `index.html` — dashboard
- `today.html` — today's study plan
- `progress.html` — progress overview
- `analysis.html` — study analysis
- `forecast.html` — forecast view
- `ideal.html` — ideal schedule view

## Project files

- `style.css` — page styling
- `script.js` — client-side interactions
